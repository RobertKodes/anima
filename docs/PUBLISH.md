# Publish the public GitHub repo

Done. Public MIT repo: https://github.com/RobertKodes/anima

Visibility is `public`. Default branch is `master`. Remote is `origin`.

```bash
git clone https://github.com/RobertKodes/anima.git
```

If you need to push later:

```bash
git push origin master
```

Do not force-push. Do not upload `wallet.json`, `.env`, or `*.db`.
